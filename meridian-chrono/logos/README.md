# Brand logos

Put brand logo files here **only once Meridian has permission to use them**, then set the path in `brandLogos` near the top of the script in `index.html`, for example:

    'Rolex': 'logos/rolex.svg',

Until a path is set, the site shows the brand name as text.

Rolex states that its name, crown and logo may not be used without its written permission, and it has taken action against independent dealers who use them. Check each brand's rules before adding its logo. A footer disclaimer does not grant permission.
