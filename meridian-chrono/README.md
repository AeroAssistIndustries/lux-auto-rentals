# Meridian Chrono Group — website prototype

A self-contained e-commerce prototype for Meridian Chrono Group (luxury watches, Scottsdale, Arizona).

- `index.html` — the whole site in one file. Open it in a browser; no build step or server needed.
- `logo/` — the Meridian emblem and lockup (SVG and PNG). `logo-build.js` regenerates them.
- `HANDOFF.md` — what's sourced, what's sample content, what to replace before launch, and test results.

Editable content (contact details, founder story, inventory, policies) sits at the top of the script in `index.html`.

**Status:** preview. Inventory includes sample listings and prices, and forms do not send anything (`demoMode: true`).
